# Siyuan Liu — Academic Homepage

Personal academic website: https://siyuan-liu99.github.io/

A static, responsive site with no build dependencies.

## Edit
- `index.html`: biography, publications, education, honors, and service.
- `style.css`: responsive layout and styling.
- `portrait.jpg`: web-ready portrait converted from the supplied HEIC photograph.
- `publications.bib`: downloadable citations. Keep these synchronized with the inline BibTeX entries in `index.html`.

## Preview
Run `python3 -m http.server 8000` in this directory, then visit http://localhost:8000.

## Publish
GitHub Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Publication metadata and acceptance status were supplied by the author. The MyoChallenge proceedings citation is provisional until the final proceedings metadata is available.
